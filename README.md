Seventeen — 17 November 2026 in one front page. A program that writes one image summing up Tuesday 17 November 2026's world news: 30 stories across 6 continents, 11 featured panels with sources, 19 briefs, and a numbered world map pinning every dateline. The artwork is generated by `build_art.py` (PIL, no network) and copied byte-for-byte by `main.py`, which verifies the PNG size, dimensions and SHA-256 before finishing.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
